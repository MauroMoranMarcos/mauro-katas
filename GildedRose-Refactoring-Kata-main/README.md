# Gilded Rose Refactoring Kata

## Original source

This kata was created by Emily Bache.

Original repository:
https://github.com/emilybache/GildedRose-Refactoring-Kata

## My goals

- Practice refactoring techniques
- Apply Clean Code principles
- Apply SOLID principles
- Apply design patterns
- Preserve existing behaviour through automated tests

## What I practiced

- Simple factory pattern
- Strategy pattern
- Favor composition over inheritance
- Single Responsibility Principle (partial)
- Open-Closed Principle (partial)
- Liskov Substitution Principle
- Interface Segregation Principle

## Notes

This repository contains my personal solution and refactoring process in C#.
