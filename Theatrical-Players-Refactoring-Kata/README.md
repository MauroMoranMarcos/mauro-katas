# Theatrical Players Refactoring Kata

## Original source

This kata was created by Emily Bache and is based on the example presented in Martin Fowler's book *Refactoring (2nd Edition)*.

Original repository:
https://github.com/emilybache/Theatrical-Players-Refactoring-Kata

## My goals

- Practice refactoring techniques
- Apply Clean Code principles
- Apply SOLID principles
- Apply design patterns
- Preserve existing behaviour through automated tests

## What I practiced

- Factory method pattern
- Strategy pattern
- Favor composition over inheritance
- Single Responsibility Principle
- Open-Closed Principle

## Notes

This repository contains my personal solution and refactoring process in C#.
