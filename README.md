# Mauro Coding Katas

Kata collection and refactoring exercises made to practice and get better in my software development skills.

## Goals

The main goal for this katas is to practice the following:

- Clean Code
- Refactoring
- TDD (Test-Driven Development)
- Object Oriented Design
- SOLID Principles
- Design patterns
- Good development practices

## Origin of the katas

All kata descriptions and starter projects used in this repository belong to their respective authors.

Solutions, modifications, refactors and tests included in this repo represent my personal work and were created for learning and practice purposes.

When possible, the original repo will be referenced for each kata.
